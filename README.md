# Threadle Playground 🧵

**English** | [한국어](README.ko.md)

Try Threadle and see how GitHub activity appears in Discord.

This repository is connected to the **Threadle Support Community**. Create an issue, leave a comment, or open a pull request to explore the notifications yourself. No coding required to get started!

## Get started

1. Join the [Threadle Support Community](https://discord.gg/6faZbNBdv).
2. Create an issue or comment on an existing one in this repository.
3. Check the connected Discord channels for Threadle’s messages and threads.

## Things to try

| GitHub activity | What to check in Discord |
| --- | --- |
| Create an issue | A notification and a dedicated issue thread |
| Add, edit, or delete a comment | Comment delivery, updates, and deletion |
| Attach an image or GIF | Media display |
| Close or reopen an issue | Status changes on the notification card and thread title |
| Open a pull request | A dedicated PR thread and related updates |
| Start a discussion | A dedicated discussion thread and comment notifications |

Some actions require repository permissions. If you cannot try a feature yourself, ask in the community!

## Before you post

- **Do not share passwords, API keys, personal information, private code, or other sensitive content.**
- Activity in this repository is also shared with the connected Discord channels and is visible to community members.
- Please avoid spam, large uploads, and disrupting other people’s tests.
- Test issues, pull requests, discussions, and Discord messages may be cleaned up periodically.

## Share your feedback

Did a notification fail to arrive? Did something look confusing or behave unexpectedly? We’d like to hear about it.

When reporting a problem, please include:

- What you did
- What you expected to happen
- What actually happened
- A link to the relevant issue, pull request, or discussion
- A screenshot, if helpful

Suggestions about wording, usability, and new features are welcome too.
