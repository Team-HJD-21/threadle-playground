# Threadle Playground 🧵

[English](README.md) | **한국어**

GitHub의 활동이 Discord에 어떻게 표시되는지 Threadle을 직접 테스트해 보세요.

이 저장소는 **Threadle Support Community**에 연결되어 있습니다. Issue를 만들거나 댓글을 남기고, PR을 열어 알림이 어떻게 전달되는지 확인할 수 있습니다. 코드를 작성하지 않아도 참여할 수 있어요!

## 시작하기

1. [Threadle Support Community](https://discord.gg/6faZbNBdv)에 참여합니다.
2. 이 저장소에서 Issue를 만들거나 기존 Issue에 댓글을 남깁니다.
3. Discord의 연결된 알림 채널에서 Threadle의 메시지와 스레드를 확인합니다.

## 이런 것들을 테스트해 보세요

| GitHub에서 해볼 활동 | Discord에서 확인할 내용 |
| --- | --- |
| Issue 만들기 | 새 알림과 해당 Issue의 스레드 |
| 댓글 작성·수정·삭제 | 댓글 전달과 기존 메시지의 갱신·삭제 |
| 이미지나 GIF 첨부 | 첨부 미디어 표시 |
| Issue 닫기·다시 열기 | 알림 카드와 스레드 제목의 상태 변화 |
| Pull Request 만들기 | PR 스레드와 관련 활동 알림 |
| Discussion 만들기 | Discussion 스레드와 댓글 알림 |

일부 활동은 저장소 권한이 필요합니다. 직접 실행할 수 없는 기능은 커뮤니티에서 테스트를 요청해 주세요!

## 테스트할 때 지켜주세요

- **개인정보, 비밀번호, API 키, 비공개 코드 등 민감한 내용은 올리지 말아 주세요.**
- 이 저장소의 활동은 연결된 Discord 채널에도 전달되며, 커뮤니티 구성원이 볼 수 있습니다.
- 다른 사람의 테스트를 방해하는 도배나 대용량 파일 업로드는 삼가 주세요.
- 테스트용 Issue·PR·Discussion과 Discord 메시지는 주기적으로 정리될 수 있습니다.

## 피드백을 기다립니다

알림이 오지 않거나, 표시가 어색하거나, 기대와 다르게 동작했다면 알려주세요.

가능하면 아래 내용을 함께 남겨주시면 확인에 도움이 됩니다.

- 어떤 활동을 했는지
- 기대했던 동작
- 실제로 발생한 동작
- 관련 Issue·PR·Discussion 링크
- 문제가 보이는 화면 캡처
